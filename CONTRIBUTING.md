# Contributing

Thank you for contributing to Nisaab360 Institution Desktop.

## Workflow

1. Open an issue or discussion for substantial behavioral changes.
2. Create a focused branch from `main`.
3. Keep changes scoped and avoid committing generated output, credentials, local databases, or environment files.
4. Run `npm run lint` and `npx tsc --noEmit`.
5. Submit a pull request describing the behavior and verification performed.

Every pull request from a non-committer must be reviewed before merge. Changes to build, release, dependency, and code-signing files require particular scrutiny because production artifacts are built from repository source.

By submitting a contribution, you agree to license it under GPL-3.0-only.
